I make films that fracture time. I write to remember what the body already knows. I teach because art is not a solo act. The work lives between languages, between geographies, between what is said and what remains unspoken. This is not a portfolio. This is a window left open.

The creative process is not linear. It spirals. It returns to the same wound with new eyes. Each project is a fragment of something larger that refuses to be named.

Between Port-au-Prince and Montreal, between Kreyol and French, between film and text -- the work exists in the gaps. The in-between is not empty. It vibrates.
